## Visões

| ------------------ | ------------------------- | -------------------------------------------------- |
| Trabalho ativo     | `is:open`                 | Backlog e execução atual sem o histórico encerrado |

| Roadmap            | `is:open`                 | Planejamento aberto, sem inventar prazos           |
| Meus itens         | `is:open assignee:@me`    | Responsabilidades já atribuídas                    |

## Convenções

- Backlog: proposta, dependência ou decisão ainda não destravada.
- Ready: escopo preparado e condições para começar conhecidas.
- In progress: implementação ou atividade operacional iniciada.
- In review: candidato publicado, revisão ou aceite ainda pendente.
- Done: issue concluída ou PR incorporado; não significa produção institucional.
- Not planned: encerramento explícito sem execução planejada.

Fechar uma issue apenas para limpar o quadro esconde trabalho. Preservar uma
issue operacional aberta depois de integrar seu roteiro é correto: escrever o
roteiro não equivale a executar recuperação, carga, observabilidade ou piloto.
Prioridades seguem risco/dependência, e não volume de commits. Não atribuir
prazos, pontos ou aceite de terceiros sem definição.
